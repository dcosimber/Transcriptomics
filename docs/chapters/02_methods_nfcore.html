5  Preprocesamiento bioinformático con nf-core/rnaseq

5.1 Objetivo del bloque

Este capítulo describe la fase de procesamiento primario del RNA-seq. Su función es documentar cómo se transformaron los FASTQ en salidas auditables de calidad, alineamiento y cuantificación. Todavía no se prueban hipótesis biológicas; se verifica que los datos tienen calidad suficiente para sostener comparaciones transcriptómicas entre regiones de piel normal y pseudoalbina.

El procesamiento se realizó con nf-core/rnaseq, usando la estrategia star_salmon: control de calidad de lecturas, filtrado con fastp, alineamiento con STAR, cuantificación con Salmon, controles post-alineamiento e integración de métricas con MultiQC.

NotaResultado técnico global

El flujo procesó 24 bibliotecas con métricas sólidas: 98.45% de lecturas retenidas tras filtrado, 94.71% de bases Q30 post-filtrado, 97.52% de alineamiento STAR total y 90.09% de alineamiento único. Estos valores apoyan el uso de las matrices Salmon gene-level como entrada principal del análisis diferencial.

5.2 Pregunta técnica

La pregunta central del preprocesamiento es si las lecturas, el alineamiento y la cuantificación son suficientemente consistentes como para interpretar diferencias de expresión sin que el resultado esté dominado por artefactos técnicos.

Para responderla se evaluaron:

  • calidad de secuenciación, bases Q30, adaptadores y composición de lecturas;
  • eficiencia de filtrado y proporción de lecturas conservadas;
  • compatibilidad con la referencia de Scophthalmus maximus;
  • orientación de biblioteca y coherencia de strandedness;
  • duplicación y complejidad de biblioteca;
  • trazabilidad de versiones, parámetros, informes MultiQC y matrices exportadas.

5.3 Configuración reproducible

La ejecución documentada corresponde a nf-core/rnaseq versión v3.25.0-g891468c, con Nextflow 25.10.3. La estrategia star_salmon combina un alineamiento genómico splice-aware con una cuantificación transcriptómica robusta.

TipPor qué STAR y Salmon

La combinación STAR + Salmon permite conservar evidencia de alineamiento genómico, útil para auditar tasas de mapeo y calidad de BAM, y al mismo tiempo obtener cuantificaciones transcriptómicas/gene-level preparadas para importación downstream. En este proyecto, Salmon gene-level se toma como matriz primaria para DESeq2.

5.4 Referencia genómica y anotación

Las lecturas se alinearon contra el ensamblado ASM1334776v1 de Scophthalmus maximus procedente de Ensembl release 113. Se utilizó el FASTA dna.toplevel, que incluye cromosomas, contigs no colocados y scaffolds, junto con la anotación completa en formato GTF.

Esta decisión es relevante en una especie no modelo. Una referencia restringida a cromosomas principales podría perder lecturas de genes anotados en regiones todavía no integradas. El uso de dna.toplevel reduce ese riesgo y mejora la coherencia entre alineamiento, anotación y cuantificación.

ImportanteIdentificadores de genes

Durante todo el análisis se mantiene ENSSMAG como identificador primario. Los símbolos, nombres funcionales y ortólogos se usan como etiquetas interpretativas, no como claves. Esta regla evita pérdidas de trazabilidad al conectar matrices, DEGs y enriquecimiento funcional.

5.5 Arquitectura del flujo

El pipeline puede leerse como una cadena de control de calidad progresivo. Cada etapa produce una salida útil para el análisis y una evidencia de auditoría para decidir si las muestras continúan hacia downstream.

5.6 Rendimiento global

El run procesó 24 bibliotecas paired-end. La profundidad media reportada por STAR fue de 24.51 millones de lecturas por muestra, con un rango entre 20.15 M (PNKV) y 42.92 M (P33). La variación de profundidad no es extrema para RNA-seq bulk y se trata posteriormente mediante normalización de tamaño de biblioteca.

5.7 Filtrado con fastp

El filtrado con fastp fue eficaz y conservador. La proporción de lecturas retenidas se mantuvo entre 97.92% y 98.84%, lo que indica que el pipeline no tuvo que descartar grandes fracciones de ninguna muestra. Este patrón evita que la normalización posterior tenga que compensar pérdidas técnicas severas entre bibliotecas.

La calidad por ciclo después del filtrado se mantuvo alta. La media de bases Q30 fue 94.71%, con valores entre 93.23% (P49) y 95.81% (P33).

5.8 Alineamiento y orientación de biblioteca

El alineamiento frente a la referencia de rodaballo fue robusto. La tasa media de alineamiento total fue 97.52%, con un rango estrecho entre 96.31% (P44) y 98.31% (PNKD). La fracción de lecturas unívocamente alineadas fue alta, con media 90.09%, mínimo 86.56% (P44) y máximo 91.71% (P48).

La comprobación de strandedness confirmó que las bibliotecas eran coherentes con una orientación reverse. Esta comprobación es importante porque una orientación mal especificada puede afectar genes solapantes, transcritos antisense y estimaciones de abundancia.

5.10 Salidas para downstream

Tras el alineamiento, star_salmon produjo cuantificaciones con Salmon y matrices agregadas a nivel de gen. Las salidas principales que alimentan el análisis downstream son:

results/nfcore_rnaseq/star_salmon/salmon.merged.gene.SummarizedExperiment.rds
results/nfcore_rnaseq/star_salmon/salmon.merged.gene_counts.tsv
results/nfcore_rnaseq/star_salmon/salmon.merged.gene_tpm.tsv

La matriz gene-level counts se usa como entrada principal para DESeq2. La matriz TPM se conserva para exploración, visualización y comprobaciones de expresión relativa, pero no sustituye a los conteos en el modelado diferencial.

5.11 Conclusión del bloque

El procesamiento primario generó una base cuantitativa adecuada para exploración de muestras, PCA, definición de contrastes y expresión diferencial. No hay evidencia de que el patrón biológico del estudio vaya a estar dominado por baja calidad de FASTQ, mala compatibilidad con la referencia o fallos globales de alineamiento.
